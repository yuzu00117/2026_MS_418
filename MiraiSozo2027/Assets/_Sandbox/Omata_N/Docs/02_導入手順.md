# エコーロケーション 導入手順

全体の仕組みは [01_全体仕様.md](01_全体仕様.md)、設定項目の詳細は [03_表示設定.md](03_表示設定.md) を参照してください。

## まず動かしてみる（デモシーン）

| シーン | 内容 |
|---|---|
| `Scenes/Scene_EchoDemo.unity` | チームの `Test_Player`・カメラ・GameManager・ポーズUIを使った基本のデモ。W で移動、E でエコーの ON/OFF、Esc でポーズ／復帰 |
| `Scenes/Scene_EchoTagEffectsDemo.unity` | 左から塗りつぶし・アウトライン・元のマテリアルの対象を並べた、表示の比較用デモ。`EchoDemoDriver` が自動でエコーを開始・停止する |
| `Scenes/Scene_EchoRevealDemo.unity` | 旧方式（`EchoRevealState`）との比較用に残しているデモ |

キー割り当ては共有の `InputSystem_Actions.inputactions` で管理しています。エコーは `Player/EchoScan` の入力から `EchoController.ToggleScan()` を呼びます。チーム入力の初期化には `GameManager` が必要です。

## 新しいシーンに導入する

**Tools → エコーロケーション → 00 新しいシーンの設定ガイド** を開くと、以下の手順を上から順に進められます。

### 1. 描画機能を準備する

エコーを画面に描くには、使用する URP Renderer に描画機能（`Echo Highlight`）が必要です。

- プロジェクト共有の `Assets/Settings/PC_Renderer.asset` と `Mobile_Renderer.asset` には登録済みです。これらを使うシーンでは作業不要です。
- 自分用の Renderer を使う場合は **Tools → エコーロケーション → 01 描画機能を準備** で追加します。共有設定を誤って変更しないよう、このツールは Omata_N 配下の Renderer だけを編集できます。
- カメラの Renderer 設定と、URP Asset の Renderer List がその Renderer を使っているか確認してください。

### 2. 発信元（EchoController）を置く

1. プレイヤー（発信する側）に `EchoController` を付けます。設定ガイドの「発信元を作成／選択した発信元を設定」でも作成できます。
2. 次の参照を設定します。

| 項目 | 設定するもの |
|---|---|
| スキャン中心 | エコーの中心にする Transform（プレイヤー本体など）。未設定なら Controller 自身 |
| 正面の基準 | 正面の向きにする Transform。未設定ならスキャン中心の forward |
| 描画カメラ | 強調表示を描く Base Camera |
| 除外するルート | 強調表示や遮断の対象から外す階層（プレイヤー自身など） |

スキャン中心はプレイヤー側に置き、三人称カメラの後退位置を中心にしないでください。

3. 入力から `SetScanEnabled(bool)` か `ToggleScan()` を呼ぶようにします（チームの入力ではすでに `ToggleScan()` を呼んでいます）。

### 3. 専用タグを作る

1. Project ウィンドウで **Create → エコーロケーション → 専用タグ** を選びます。設定ガイドの「専用タグアセットを新規作成」でも作れます（保存先は `Settings/EchoTags/`）。
2. 名前はアセット命名規則に合わせて `SO_ET_用途` のようにします。
3. アセットを選択し、Inspector で表示・遮断・実体化を設定します（[03_表示設定.md](03_表示設定.md#専用タグ)）。

### 4. 物体に EchoTarget を付ける

1. エコーで表示したい物体のルートに `EchoTarget`（Add Component → Echo → Echo Target）を付けます。
2. 「専用タグ」に手順 3 のアセットを指定します。

1 つずつ付ける代わりに、**Tools → エコーロケーション → 03 対象に専用タグを付与** で、Unity のタグから対象を探してまとめて付けられます。

1. 「検索するUnityタグ」と「付与する専用タグ」を選びます。
2. 「現在のシーンだけ」「選択した階層だけ」「非アクティブも含む」「既存の専用タグを置換」を必要に応じて設定します。
3. 「対象をプレビュー」で対象を確認し、「プレビュー対象に適用」を押します。Undo できます。Unity のタグは変更しません。

### 5. 保存して確認する

シーンを保存して再生し、エコーを発信して表示・遮断を確認します。表示されないときは、[うまく表示されないとき](#うまく表示されないとき) を確認してください。

Controller の Inspector 下部の「セットアップを検証」ボタンでも、設定の抜け（描画カメラ・描画機能・URP・非対応の Renderer など）を確認できます。結果は Console に出ます。

## 任意で追加するもの

| コンポーネント | 用途 |
|---|---|
| `EchoStockDisplay`（Echo → Echo Stock Display） | 単発方式のストック数（例：`ECHO 2 / 3`）と回復ゲージを画面の隅に表示する。どの GameObject に付けてもよい（Controller 未設定ならシーン内から探す） |
| `EchoFrameRateLimiter`（Echo → Frame Rate Limiter） | FPS の上限を設定する。コンポーネントを無効にすると適用前の設定に戻る |

## 動的に生成する物体

- 生成する Prefab には `EchoTarget` を付けてください。付けておけば自動で登録されます。
- `EchoTarget` を付けずに自動収集だけを使う場合は、生成後に `EchoController.RefreshTargets()` を呼びます。
- 子 Renderer や LOD の構成を実行中に変えた場合は、`EchoTarget.RefreshRenderers()` を呼びます。

## シーンを編集するときの注意

- `Scene_EchoDemo` はチーム共有の Prefab（`Test_Player` など）を使っています。エコーの調整はシーンの Override として保存し、共有 Prefab へ Apply しないでください。
- 共有 Prefab に残っている旧コンポーネントは外せませんが、再生中は値を引き継ぐので動作は変わりません。外す場合は Prefab の担当者と相談してください。

## 既存シーンの移行

古い構成（旧 `EchoTag`・`EchoRangeDisplay`・`EchoRevealWorld` や、Controller の Unity タグ別設定）を使っているシーンは、次のメニューで移行できます。

| メニュー（Tools → エコーロケーション → 既存シーンの移行） | 内容 |
|---|---|
| コンポーネントを統合（開いているシーン） | 開いているシーンの旧コンポーネントの値を `EchoTarget`・`EchoController` へ移し、旧コンポーネントを外す。保存はしないので、確認してから保存する |
| コンポーネントを統合して保存（Omata_Nの全シーン） | Omata_N 配下の全シーンに同じ処理をして保存する |
| 旧Unityタグ設定を専用タグへ変換 | 現在のシーンの Controller にある Unity タグ別の表示・遮断設定を、専用タグアセット（`Settings/EchoTags/`）へ移す。Controller が複数あるシーンでは使えない |

どのメニューも、他のメンバーの共有シーンを変えないよう Omata_N 配下のシーンだけを対象にします。再生を止めてから実行してください。

## うまく表示されないとき

| 症状 | 確認すること |
|---|---|
| 何も表示されない | 使用中の Renderer に描画機能があるか（手順 1）。Controller の「描画カメラ」が実際のカメラか |
| 特定の物体だけ表示されない | `EchoTarget` が付いているか。専用タグが指定され、①②③のどれかが「表示する」になっているか。Controller の「対象レイヤー」に含まれているか。「除外するルート」の配下にないか |
| 壁の裏にある物体が表示されない | 発生位置から見て遮断されている。手前の物体のタグで「エコーロケーションを遮断する」をオフにするか、Controller の「影になる部分を強調しない」を確認する |
| 透明な物体が実体化しない | 専用タグの「実体化までの照射時間」と「照射が途切れたとき」の設定。照射中の表示がすべてオフでも接触の判定は続くので、時間の設定を確認する |
| 範囲表示が出ない | Controller の「スキャン範囲を表示」がオンか |
