# WaveRider 使い方(タスク 3001 / 3003)

## 目的
タレットなどが出す波(ビーム)の線に沿って、物と、その上に乗っているプレイヤーを運ぶ。
波が曲がっても反射しても、線の上の道のりを保ったまま線に沿って進む。

## すぐ使う
1. `Assets/_Sandbox/Miyata_M/Prefabs/PF_WaveRider.prefab` をシーンに置く(1×1×1 のキューブ)
2. 波を出すタレットの経路の近くに置く
3. 「乗る波を出すもの」にタレット(WaveEmitter)を**必ず**入れる(プレハブでは空。空のままだと起動時にエラーが出て、波に乗らない)
4. 見た目を変えるときは、子のメッシュを足して、MeshRenderer だけ差し替える。サイズは Scale で変える

プレハブの初期設定:
- 電磁波に反応する(超音波には反応しない)
- Substance は `SO_Substance_WaveRiderBody`(波への反応が PassThrough)
- 線からの高さのずれは 0.5(1m のキューブの半分の高さ)。大きさを変えたら合わせる

## コードから使う
- コードで生成したときは、生成後に `SetEmitter(WaveEmitter)` で「乗る波を出すもの」を割り当てる(乗っていた波からは降りる)

- 戻る先の初期位置は、生成時(Awake)の位置。生成したあとに位置を動かしたときは、`SetInitialPosition(Vector3)` で戻る先を指定する
- 戻るときの向きも、生成時(Awake)の向き。生成したあとに向きを変えたときは、`SetInitialRotation(Quaternion)` で指定する
- 無効のまま生成したときなど、Awake より前に `SetInitialPosition` / `SetInitialRotation` を呼んでも、Awake でその値を上書きしない

## 構成するもの
| コンポーネント | 役割 |
|---|---|
| WaveReaction | どの種類の波に反応するか(電磁波 / 超音波) |
| WaveRider | 波の線に沿って動く本体。Rigidbody は Awake で Kinematic になる |
| Substance | `SO_Substance_WaveRiderBody` を入れる。ビームが自分の面で止まって線が縮むのを防ぐ |
| BoxCollider | 当たり判定。**自分自身に付ける**(子には付けない) |

## 設定(WaveRider)
| 項目 | 内容 |
|---|---|
| 乗る波を出すもの | 必須。この WaveEmitter の波だけに乗る。空だと Awake でエラーを出す |
| 運ばれる速さ(m/s) | 線に沿って進む速さ。0 なら乗っても進まない |
| 波が無くなったとき | その場で止まる / 慣性で進んでから止まる / 初期位置へ戻る(まっすぐ) / 経路探索で初期位置へ戻る(NavMesh) |
| 慣性の減速(m/s²) | 「慣性」のとき。大きいほど早く止まる。0 なら止まらない。壁に当たれば手前で止まる。初速は、波が無くなる直前のステップで実際に動いた速さ(壁に押し付けられて動けなかった向きの分は入らない)。ただし「運ばれる速さ」までに抑える(砲台が回るなどで線を追って速く動いていても、降りた理由によらず、遠くへ飛んでいかない)。「運ばれる速さ」が 0 なら、降りても慣性では進まない |
| 戻る速さ(m/s) | 「初期位置へ戻る」「経路探索で初期位置へ戻る」のとき。0 なら戻らずその場で止まる。途中に壁などがあれば、その手前で止まる |
| 最初に乗れる距離(m) | 最初に乗るとき、線までの距離がこれ以内のときだけ乗る。遠くから壁越しに引き込まれない(初期値 3) |
| 乗り直せる距離(m) | 一度乗ったあと、線までの距離がこれ以内のときだけ乗り直す。最後に乗っていた間に線から離れていた分(乗った時点のずれ、押し戻し)は、これに足して許す(波が無い間に慣性や戻る動きで動いたら、足さない)。波が無い間に初期位置にいれば(戻り終えたときなど)、「最初に乗れる距離」で乗る |
| 線からの高さのずれ(m) | 線から真上へずらす量。足元の高さ合わせに使う |
| 線へ寄る速さ(m/s) | 乗った時点で線から離れていたとき、少しずつ寄る速さ。0 なら寄らない |
| 線に付いていく速さの上限(m/s) | 砲台が回ったり波が曲がったりして線そのものが動いたとき、線に付いていく速さの上限(初期値 10)。速く動く線には遅れて付いていく。「運ばれる速さ」+「線へ寄る速さ」より小さくても、そちらを上限にする |
| 線から遅れて降りる距離(m) | 線が速く動いて追いつけず、線からこれより遅れたら波から降りる(初期値 1)。降りたあとは「波が無くなったとき」の動きになり、線が「乗り直せる距離」まで近づけば乗り直す。壁際で線から離れる向きに押し戻された分(反射の曲がり角で大きいライダーが押し戻される分など)は遅れに数えない(横の壁から押し戻されている間に線が前後へ動いた分は、遅れに数える)。0 なら降りずに追いかけ続ける |
| 進む向きに回転を合わせる | オンで線の進む向き(Y 軸まわり)を正面にする。上の物も中心まわりに一緒に回る |
| 終点に着いたとき | 終点で止まる / 折り返す(波が出ている間、往復する) |
| 初期位置へ戻り終えたとき | 波に乗ったあと、「初期位置へ戻る」系で初期位置(向きを合わせる設定なら初期の向きも)に着いたときに 1 回呼ぶ UnityEvent。壁に阻まれて着けないときは呼ばない |
| 上の物を運ぶ | プレイヤーを乗せるならオンのまま |
| スイッチで起動する | オンなら、スイッチが起動している間だけ波に乗る |
| 始めから起動しておく | 「スイッチで起動する」がオンのとき、開始時から起動しているか |

## スイッチとつなぐ
1. 「スイッチで起動する」をオンにする
2. スイッチ(`ReactionTrigger`、`PressurePlate` など)の `On Activated` に `WaveRider.Activate`、`On Deactivated` に `WaveRider.Deactivate` をつなぐ
3. 止まっている間は、波が無いときと同じ動きになる(「波が無くなったとき」の設定に従う)
4. このライダーの Awake より前に Activate / Deactivate が呼ばれても(別の物の Awake からスイッチのイベントが来たときなど)、その状態を残す。「始めから起動しておく」は、何も呼ばれていないときだけ使う

## 動きのきまり
- 波が出ている間は常に線の上にいる。乗った時点で線から離れていれば、「線へ寄る速さ」で寄る
- 終点の近く(先頭が終点を越える所)で乗ったときも、終点で止まる所から「線へ寄る速さ」で寄る(一気に戻されない)
- 線の終点では、先頭(前面)が終点に着いたところで止まる。中芯が壁面に食い込まない
- 折り返すときの線の始まり(砲台側)でも、後ろ側の広がり分だけ手前で折り返す。砲台に食い込まない
- 線がライダーの前後の広がりの合計以下に短いときは、動ける余地が無いので、終点側の端に留まる(折り返さない)
- 反射壁などに食い込んだ分は、横方向に押し戻す。押し戻さないもの:
  - 自分の子
  - 波を出している物(タレット)の子
  - 動く Rigidbody
  - ほかの WaveRider
  - 縦に重ならない物(床)
- 上に乗った Rigidbody は、同じ移動量で運ぶ(プレイヤーは毎ステップ水平の速度を入力で上書きするため、摩擦では運ばれない)
- 上に乗った物は、自分の向き(Y 軸まわり)に合わせた上面の範囲で探す。回っていても、上面の外の角の物は運ばない(BoxCollider 以外の形は、軸平行の箱で代えるので少し広めになる)
- 2 つのライダーにまたがって乗った物は、1 ステップに 1 回だけ運ぶ(そのステップで先に動いたライダーの動きを使う)
- 「上の物を運ぶ」がオンのときは、開始時に自分と子の Collider の摩擦を 0 にする(材質が無ければ摩擦 0 の材質を付け、あれば複製して摩擦だけ 0 にする)。子が増えたときも同じにし、子から外れた Collider とライダーが消えるときは元の材質へ戻す。ライダーは `MovePosition` で動くので、摩擦が残っているとライダーの速さが上の物に伝わり、運ぶ処理の分と合わせて 2 倍進むため。オフのときは摩擦だけが上の物を動かすので、材質は変えない
- 摩擦が 0 なので、上の物が自分で動いている(押された、転がった)ときは、ライダーの上では止まらずに滑り続ける。上の物の材質の摩擦の合わせ方が Maximum のときは、その物の摩擦が残り、2 倍進む問題が残る
- 「初期位置へ戻る」系で戻る間は、向きも初期の向きへ少しずつ戻す(「進む向きに回転を合わせる」がオンで、「戻る速さ」が 0 より大きいときだけ)
- 戻りながら回るとき、回ると壁に横から食い込むなら、そのステップは回さない(位置が動いて空けば、また回る)
- 「慣性」「初期位置へ戻る」系で動く間も、動く Rigidbody(箱、プレイヤーなど)では止まらず、物理で押しのける(乗っている間と同じ)。止まるのは、動かない物(壁など)と Kinematic の物だけ
- 「慣性」「初期位置へ戻る」系で動き始めたとき、もう壁に食い込んでいれば、その壁へさらに入り込む向きには進まない(離れる向きと、壁の面に沿う向きには進む)
- 波が無くなったあと、波が戻れば、今の位置に一番近い線の上の点から乗り直す

## 経路探索で戻る(NavMesh)
- 「波が無くなったとき」を「経路探索で初期位置へ戻る」にすると、NavMesh の経路で壁を避けて初期位置へ戻る
- シーンに NavMesh のベイクが必要。ライダー自身は NavMesh に含めない(動く物なので、レイヤーを分けて除外する)
- 「エージェントの半径」をライダーの横幅の半分以上にしてベイクすると、壁の角に引っかからない
- NavMesh が無い、または経路が引けないときは、警告を 1 回出して、まっすぐ戻る
- 空中を運ばれた高さからは、10m 以内の NavMesh の最寄りの点に置き換えて経路を引く。高さのずれは、先に「戻る速さ」で縮めてから、経路を進む(速さが「戻る速さ」を超えない)
- 途中で壁に当たって止まったら、今の位置から経路を引き直す

## 制限
- **波を透過するオブジェクトが波の軌道上にある場合は非対応**
- 凹形の MeshCollider は `ComputePenetration` が使えず、押し戻せない(Box など凸形は問題なし)
- 波の終点が壁でなく空中でも、前面の広がり分だけ手前で止まる
- 押し戻しと、上に乗った物の検出の重なりバッファは 32 個まで。上面でこれを超えると、警告を 1 回出す
- 押し戻しは自分の Collider ごとに求め、一番大きいものだけを使う(子に Collider を付けても二重に押さない)
- 乗っている間は、壁の手前で止める処理をしない。線が動いて壁の向こうへ移っても、1 ステップに動く量(「線に付いていく速さの上限」と「運ばれる速さ」+「線へ寄る速さ」の大きいほう × 物理ステップ)が壁の厚みの半分より小さければ、押し戻しで手前に残る。薄い壁は抜けることがある。線が大きく離れたときは「線から遅れて降りる距離」で降りるので、遠くまでは追いかけない
- 上に乗った物は、壁の手前で止める処理をしない(毎ステップの確保を避けるため)。壁際で壁に食い込んだ分は、物理の押し出しに任せる
- 重力は受けない(Kinematic)。空中で波が途切れると、「その場で止まる」ではその高さに浮いたまま、「慣性」では浮いたまま進む(「慣性の減速」が 0 なら、壁に当たるまで進み続ける)。浮いたままにしたくないときは「初期位置へ戻る」系を使う
- 初期位置はワールド座標で覚える。動く親(動く床など)の子にすると、戻る先がずれる
- 経路探索で戻るとき、最寄りの NavMesh の点が別の階の床になることがある(10m 以内で一番近い点を使うため)
- WaveRider どうしは、乗っている間も、慣性や戻る動きの間も、互いにぶつからない(押し戻さず、止まらず、すり抜ける)。すり抜けるのは有効な WaveRider だけで、コンポーネントを無効にした WaveRider は壁と同じく押し戻す
- 上の物は位置を直接書き換えて運ぶので、Rigidbody の補間(Interpolate)を使う物は、見た目が少し揺れることがある
- 「初期位置へ戻り終えたとき」は、位置と向きがそろったその物理ステップで呼ぶ(向きは、そのステップで回ったあとの向きで判定する)
- 検証したのは 3×1×3 と 1×1×1(プレハブ)のライダー。実際の Phononkinesis の曲がる波、電磁スイッチと実際の波の組み合わせは未確認
