# WaveRider 使い方(タスク 3001)

## 目的
タレットなどが出す波(ビーム)の線に沿って、物と、その上に乗っているプレイヤーを運ぶ。
波が曲がっても反射しても、線の上の道のりを保ったまま線に沿って進む。

## すぐ使う
1. `Assets/_Sandbox/Miyata_M/Prefabs/PF_WaveRider.prefab` をシーンに置く(1×1×1 のキューブ)
2. 波を出すタレットの経路の近くに置く
3. 「乗る波を出すもの」にタレット(WaveEmitter)を入れる。空でもよい(下の「設定」を参照)
4. 見た目を変えるときは、子のメッシュを足して、MeshRenderer だけ差し替える。サイズは Scale で変える

プレハブの初期設定:
- 電磁波に反応する(超音波には反応しない)
- Substance は `SO_Substance_WaveRiderBody`(波への反応が PassThrough)
- 線からの高さのずれは 0.5(1m のキューブの半分の高さ)。大きさを変えたら合わせる

## 構成するもの
| コンポーネント | 役割 |
|---|---|
| WaveReaction | どの種類の波に反応するか(電磁波 / 超音波) |
| WaveRider | 波の線に沿って動く本体。Rigidbody は Awake で Kinematic になる |
| Substance | `SO_Substance_WaveRiderBody` を入れる。ビームが自分の面で止まって線が縮むのを防ぐ |
| BoxCollider | 当たり判定。**自分自身に付ける**(子には付けない) |

## 設定(WaveRider)
| 項目 | 内容 |
|---|---|
| 乗る波を出すもの | 空なら、反応する波を出している中で、今の位置から一番近い線に乗る |
| 運ばれる速さ(m/s) | 線に沿って進む速さ。0 なら乗っても進まない |
| 波が無くなったとき | その場で止まる / 慣性で進んでから止まる / 初期位置へ戻る |
| 慣性の減速(m/s²) | 「慣性」のとき。大きいほど早く止まる。0 なら止まらない。壁に当たれば手前で止まる |
| 戻る速さ(m/s) | 「初期位置へ戻る」のとき。0 なら戻らずその場で止まる |
| 乗り直せる距離(m) | 一度乗ったあと、線までの距離がこれ以内のときだけ乗り直す |
| 線からの高さのずれ(m) | 線から真上へずらす量。足元の高さ合わせに使う |
| 線へ寄る速さ(m/s) | 乗った時点で線から離れていたとき、少しずつ寄る速さ。0 なら寄らない |
| 進む向きに回転を合わせる | オンで線の進む向き(Y 軸まわり)を正面にする。上の物も中心まわりに一緒に回る |
| 終点に着いたとき | 終点で止まる / 折り返す(波が出ている間、往復する) |
| 上の物を運ぶ | プレイヤーを乗せるならオンのまま |
| スイッチで起動する | オンなら、スイッチが起動している間だけ波に乗る |
| 始めから起動しておく | 「スイッチで起動する」がオンのとき、開始時から起動しているか |

## スイッチとつなぐ
1. 「スイッチで起動する」をオンにする
2. スイッチ(`ReactionTrigger`、`PressurePlate` など)の `On Activated` に `WaveRider.Activate`、`On Deactivated` に `WaveRider.Deactivate` をつなぐ
3. 止まっている間は、波が無いときと同じ動きになる(「波が無くなったとき」の設定に従う)

## 動きのきまり
- 波が出ている間は常に線の上にいる。乗った時点で線から離れていれば、「線へ寄る速さ」で寄る
- 線の終点では、先頭(前面)が終点に着いたところで止まる。中芯が壁面に食い込まない
- 反射壁などに食い込んだ分は、横方向に押し戻す。押し戻さないもの:
  - 自分の子
  - 波を出している物(タレット)の子
  - 動く Rigidbody
  - 縦に重ならない物(床)
- 上に乗った Rigidbody は、同じ移動量で運ぶ(プレイヤーは毎ステップ水平の速度を入力で上書きするため、摩擦では運ばれない)
- 波が無くなったあと、波が戻れば、今の位置に一番近い線の上の点から乗り直す

## 制限
- **波を透過するオブジェクトが波の軌道上にある場合は非対応**
- 凹形の MeshCollider は `ComputePenetration` が使えず、押し戻せない(Box など凸形は問題なし)
- 波の終点が壁でなく空中でも、前面の広がり分だけ手前で止まる
- 押し戻しの重なり検出バッファは 32 個まで
- 検証したのは 3×1×3 のライダーのみ。1×1×1、実際の Phononkinesis の曲がる波、電磁スイッチと実際の波の組み合わせは未確認
