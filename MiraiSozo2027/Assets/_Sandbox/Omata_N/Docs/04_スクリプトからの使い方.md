# エコーロケーション スクリプトからの使い方

ほかのスクリプトからエコーを操作したり、状態を読んだりする方法です。名前空間は `Echo.Echolocation` です。使える変数・関数の一覧は [05_API一覧.md](05_API一覧.md) にあります。

## 参照の取り方

`EchoController`（プレイヤー側）と `EchoTarget`（物体側）は、Inspector で参照を渡すか、`Awake` で取得してキャッシュします。`Update` の中で `GetComponent` や `Find` を呼ばないでください。

```csharp
using Echo.Echolocation;
using UnityEngine;

public sealed class EchoUser : MonoBehaviour
{
    [SerializeField] private EchoController _echo;   // Inspector で指定する
    private EchoTarget _target;

    private void Awake() => _target = GetComponent<EchoTarget>();
}
```

カメラから Controller を探す場合は `EchoController.GetForCamera(camera)` を使えます（同じカメラを指定した Controller が複数あると `null`）。

## 1. エコーを ON／OFF する

```csharp
_echo.SetScanEnabled(true);   // ON
_echo.SetScanEnabled(false);  // OFF
_echo.ToggleScan();           // 反転
```

- 操作は次の `LateUpdate` でまとめて反映されます。
- 同じ操作から複数回呼ばないでください（`ToggleScan` を 2 回呼ぶと元に戻ります）。
- 単発方式では、ON と切り替えのどちらでも波を 1 つ打ちます。OFF は「停止時の消し方」が「即時」のときだけ、伝播中の波を消します。
- ライト方式で持続可能な時間を使い切り、「自動でOFFになる」設定のときは、回復するまで ON の操作は無視されます。

## 2. エコーを使っているか知る

```csharp
using Echo.Echolocation;
using UnityEngine;

public sealed class EchoBatteryDrain : MonoBehaviour
{
    [SerializeField] private EchoController _echo;
    [SerializeField] private float _drainPerSecond = 5f;
    private float _battery = 100f;

    private void OnEnable() => _echo.UsageChanged += HandleUsageChanged;
    private void OnDisable() => _echo.UsageChanged -= HandleUsageChanged;

    private void Update()
    {
        // 使用中だけ毎フレーム減らす。
        if (_echo.IsEchoInUse)
            _battery -= _drainPerSecond * Time.deltaTime;
    }

    private void HandleUsageChanged(bool isInUse)
    {
        // 開始・終了の瞬間だけ処理したい場合はイベントを使う。
    }
}
```

| 知りたいこと | 使うもの |
|---|---|
| エコーを使っているか（OFF 後に波が消えきるまで含む） | `IsEchoInUse` / `UsageChanged` |
| ON／OFF の操作状態だけ | `IsScanRequested` |
| 非表示・展開中・表示中・消去中の細かい状態 | `CurrentState` / `StateChanged`（Inspector からは「状態変更時の通知」） |

## 3. ライト方式の持続可能な時間を使う

残り時間をゲージに表示し、アイテムで回復させる例です。実際に使うときは、1 ファイル 1 クラスのルールに合わせて 2 つのファイルに分けてください。

```csharp
using Echo.Echolocation;
using UnityEngine;
using UnityEngine.UI;

public sealed class EchoSustainGauge : MonoBehaviour
{
    [SerializeField] private EchoController _echo;
    [SerializeField] private Image _gauge;          // Image Type を Filled にしておく

    private void Update() => _gauge.fillAmount = _echo.LightSustainRatio;
}

public sealed class EchoBatteryItem : MonoBehaviour
{
    [SerializeField] private EchoController _echo;
    [SerializeField] private float _recoverSeconds = 3f;

    // 拾ったときに呼ぶ。
    public void HandlePickedUp() => _echo.RecoverLightSustain(_recoverSeconds);
}
```

- `LightSustainRatio` は 0〜1 です。時間制限なしの設定では常に 1 です。
- `LightSustainRemainingSeconds` で残りの秒数も読めます。時間制限なしの設定では 0 です。
- 「回復のしかた」が「回復しない」の場合は、`RecoverLightSustain(秒数)` か `RefillLightSustain()`（満タン）で回復させます。どちらも持続可能な時間を超えては回復しません。

## 4. 単発方式のストックを使う

```csharp
private void OnEnable() => _echo.OnceStockChanged += HandleStockChanged;
private void OnDisable() => _echo.OnceStockChanged -= HandleStockChanged;

private void HandleStockChanged(int stock)
{
    // ストック数が変わった瞬間の処理（効果音など）。
}
```

- `OnceStock` で今打てる回数、`Settings.OnceStockCapacity` で最大数を読めます。
- `OnceRechargeProgress`（0〜1、満タンなら 1）で次の回復までの進み具合を読めます。
- 画面表示だけなら `EchoStockDisplay` を付ければ、コードを書かずに表示できます。

## 5. 物体がエコーで見えているか知る

```csharp
using Echo.Echolocation;
using UnityEngine;

[RequireComponent(typeof(EchoTarget))]
public sealed class EnemyRevealReaction : MonoBehaviour
{
    private EchoTarget _target;

    private void Awake() => _target = GetComponent<EchoTarget>();
    private void OnEnable() => _target.RevealChanged += HandleRevealChanged;
    private void OnDisable() => _target.RevealChanged -= HandleRevealChanged;

    private void HandleRevealChanged(EchoTarget target, bool isRevealed)
    {
        // 見つかった瞬間（isRevealed == true）・見えなくなった瞬間の処理。
    }
}
```

| 知りたいこと | 使うもの |
|---|---|
| ①②③のどれかで表示されているか（残存表示中も含む） | `IsRevealed` / `RevealChanged` |
| 波が今届いているか（残存は含まない） | `IsInContact` |
| 最後に波が届いた時刻 | `LastContactTime`（Controller の「時間の基準」に合わせた時刻。未接触は負の無限大） |

## 6. 透明な物体の実体化を使う

専用タグで「通常の描画を隠す」をオンにした物体は、透明・照射中・実体化の状態を持ちます。

```csharp
using Echo.Echolocation;
using UnityEngine;

[RequireComponent(typeof(EchoTarget))]
public sealed class HiddenBridge : MonoBehaviour
{
    private EchoTarget _target;

    private void Awake() => _target = GetComponent<EchoTarget>();
    private void OnEnable() => _target.StateChanged += HandleStateChanged;
    private void OnDisable() => _target.StateChanged -= HandleStateChanged;

    private void HandleStateChanged(EchoTarget target, EchoMaterializationState state)
    {
        if (state == EchoMaterializationState.Materialized)
        {
            // 実体化した瞬間の処理（効果音・ギミックの起動など）。
        }
    }

    // スイッチなどから、照射を待たずに実体化させる。
    public void HandleSwitchPressed() => _target.Materialize();
}
```

| 知りたいこと・やりたいこと | 使うもの |
|---|---|
| 今の状態 | `State`（`Transparent` / `Irradiated` / `Materialized`）、`IsMaterialized` |
| 状態が変わった瞬間 | `StateChanged` |
| 実体化までの進み具合 | `MaterializationProgress`（0〜1、実体化中は 1）、`IrradiationSeconds`（蓄積した照射時間） |
| 照射を待たずに実体化させる | `Materialize()` |
| 透明に戻す（蓄積も 0 に戻す） | `ResetToTransparent()` |

- 「通常の描画を隠す」がオフの専用タグの物体は、常に `Materialized` です。`Materialize()` と `ResetToTransparent()` は何もしません。
- 「透明な間は当たり判定を無効にする」がオンなら、実体化した時点で Collider が有効に戻ります。

## 7. 設定を実行中に変える

```csharp
// Controller の設定（このController だけに効く）
_echo.Settings.Radius = 15f;
_echo.Settings.LightSustain.HasSustainLimit = true;

// 専用タグの設定（同じアセットを使う全部の物体に効く）
_target.Definition.Settings.Materialization.RequiredSeconds = 2f;
```

- Controller の設定は次の `LateUpdate` で反映されます。最大半径・全開き角・伝播時間・スキャン方式・停止時の消し方・時間の基準・再展開間隔・残存時間を ON の間に変えると、広がりが最初からやり直しになります。
- 設定をまとめて差し替える場合は `ApplySettings(settings)` を使います。渡した設定はコピーされるので、渡した後に元の設定を変えても影響しません。
- 専用タグの設定はアセットなので、エディタで再生中に変えるとアセットに残ります。物体ごとに変えたい場合は、別の専用タグアセットを用意して `EchoTarget.Definition` を差し替えてください。

## 8. 物体を生成・変更したとき

- 生成する Prefab に `EchoTarget` が付いていれば、自動で登録されます。
- `EchoTarget` を付けない物体を自動収集に含めたい場合は、生成後に `_echo.RefreshTargets()` を呼びます（全検索で重いので、毎フレームは呼ばない）。
- 子 Renderer や LOD を実行中に変えた場合は、`_target.RefreshRenderers()` を呼びます。
- 通常の描画を隠している間に元のマテリアルを取得したい場合は、`EchoTargetRegistry.GetOriginalMaterials(renderer)` を使います（`renderer.sharedMaterials` は一時的な透明マテリアルを返します）。

## 注意点

- **1〜3 フレーム遅れる**：接触は GPU で判定し、非同期で読み戻します。`IsRevealed`・`IsInContact`・`LastContactTime`・実体化の状態は、画面の表示より少し遅れて変わります。
- **最初に参照した時点から追跡を始める**：読み戻しの負荷を必要な物体だけにかけるため、`IsRevealed`・`IsInContact`・`LastContactTime` を初めて読んだとき、または `RevealChanged` を購読したときから判定を始めます。開始直後から必要なら、`Start` などで一度読んでおいてください（通常の描画を隠す物体は、実体化の判定のため常に追跡します）。
- **判定は描画結果と同じ**：発生位置から壁で遮断されて表示されていない物体は `false` です。
- **表示設定がない物体は常に `false`**：専用タグが未設定、または①②③がすべてオフの物体は表示されないため、`IsRevealed` は `false` です。
- **描画カメラが動いている間だけ更新**：判定は Controller の描画カメラの描画の中で行います。カメラや Controller が無効の間は `false` になります。画面外の物体は、カメラが有効なら判定されます。
- **イベントは必ず解除する**：`OnEnable` で `+=` したら、`OnDisable` で `-=` してください。
