# エコーロケーション 全体仕様

プレイヤーから「エコー」を発信し、届いた範囲の物体を強調表示する仕組みです。Unity 6000.6.3f1 / URP（RenderGraph）で動作します。実装はすべて `Assets/_Sandbox/Omata_N/` 配下にあり、名前空間は `Echo.Echolocation` です。

## 全体の構成

```
プレイヤー側                         物体側
┌─────────────────┐            ┌──────────────────┐
│ EchoController  │ ─ 波 ─▶   │ EchoTarget       │
│  ・スキャン方式   │            │  ・専用タグ参照     │
│  ・半径/角度/時間 │            │  ・透明/照射中/実体化│
│  ・範囲表示       │            └────────┬─────────┘
│  ・遮蔽（影）     │                     │ 参照
└─────────────────┘            ┌────────▼─────────┐
                               │ 専用タグ（アセット）│
URP Renderer Feature           │  EchoTagDefinition │
 └ 強調表示・範囲表示を描画      │  ・遮断するか        │
                               │  ・表示①②③の設定    │
                               │  ・実体化の条件      │
                               └──────────────────┘
```

| 要素 | 役割 |
|---|---|
| `EchoController` | プレイヤーに付けるコンポーネント。エコーの発信・範囲・方式・範囲表示・遮蔽を管理する |
| `EchoTarget` | エコーで表示したい物体のルートに付けるコンポーネント。専用タグを指定し、子Rendererをまとめて1つの物体として扱う |
| 専用タグ（`EchoTagDefinition`） | ScriptableObject のアセット。表示のしかた・遮断するか・実体化の条件を持つ。同じアセットを使う物体は設定を共有する |
| 描画機能（`EchoUrpRendererFeature`） | URP Renderer に追加する描画機能。強調表示とスキャン範囲を画面に描く |
| `EchoStockDisplay`（任意） | 単発方式のストック数を画面に表示する UI |
| `EchoFrameRateLimiter`（任意） | FPS の上限を設定する |

## 用語

| 用語 | 意味 |
|---|---|
| エコー／波 | Controller から球（または扇形）状に広がる検出範囲 |
| 最大半径 | 波が届く最大の距離（m） |
| 全開き角 | 正面を中心とした検出範囲の角度（度）。360 で全方向、180 で前半分 |
| 伝播時間 | 半径 0 から最大半径まで広がるのにかかる秒数 |
| 接触 | 波がその物体の表面に届いていること |
| 残存 | 接触が終わった後も、設定した秒数だけ表示を残すこと |
| 遮断 | 物体が波を止め、その裏側に波が届かなくなること |
| 専用タグ | Unity のタグとは別の、エコー専用の分類アセット |
| 照射 | 透明な物体にエコーが当たっている状態 |
| 実体化 | 一定時間照射された透明な物体が、通常の描画で見えるようになった状態 |

## スキャン方式

Controller の「スキャン方式」で 3 つから選びます。

| 方式 | 動き |
|---|---|
| **ライト方式** | プレイヤーの位置・向きに追従する範囲を照らし続ける。ON で広がり、OFF で消える。持続可能な時間を設定できる |
| **断続方式** | ON の直後に 1 つ、その後は一定間隔ごとに波を出し直す。各波は出した位置・向きに固定され、広がりきった後も設定秒数だけ残る。同時に存在できる波は最大 64 |
| **単発方式** | ON（または切り替え）のたびに、その位置・向きから帯状の波を 1 つ出す。帯が通り過ぎた場所は当たっていない扱い。ストック制で、連続で打てる回数と回復時間を設定できる。全部の波が抜けきると自動で OFF に戻る |

### ON／OFF と状態

`EchoController.CurrentState` は次の 4 つの段階を持ちます。

| 状態 | 意味 |
|---|---|
| `Hidden` | 非表示 |
| `Revealing` | 展開中（広がっている途中） |
| `Active` | 表示中（広がりきった） |
| `Hiding` | 消去中（OFF にして消えている途中） |

OFF にしたときの消え方は「停止時の消し方」で選びます。

- **即時**：その場で消える。
- **手前から順番**：中心から外側へ消していく。単発方式では伝播中の波が最後まで進む。

時間は「時間の基準」で、ゲーム時間（ポーズ中は止まる）か実時間（ポーズ中も進む）を選びます。

### ライト方式の持続可能な時間

「持続可能な時間を設定する」にチェックを入れると、ON の間だけ時間を消費します。チェックなしなら時間制限はありません。

- **使い切ったとき**：「自動で OFF になる」か「最小の範囲で照らし続ける」。自動で OFF になる設定では、少しでも回復するまで ON にできません。
- **回復のしかた**：「OFF の間に回復する」（回復する速さを指定）、「OFF にすると満タンに戻る」、「回復しない」（スクリプトから回復させる）。
- **範囲を狭める**：「最大半径を狭める」「全開き角を狭める」をそれぞれ選べる。チェックした項目は、残り時間に合わせて最大値から「0 になった時の最小値」へ少しずつ狭まる。広がる速さは最大半径を基準のまま変わらない。
- 持続可能な時間の秒数やチェックを変えると、満タンから始まる。

## 専用タグと表示

物体の表示のしかたは、`EchoTarget` に指定した専用タグのアセットで決まります。Controller 側の旧タグ一覧や Unity のタグは表示に使いません。

### 3 種類の表示

| 表示 | 内容 |
|---|---|
| ① 塗りつぶしによる強調表示 | 波が届いた表面を指定色で塗る |
| ② アウトラインによる強調表示 | 物体のシルエットの内側に輪郭線を描く |
| ③ 元のマテリアルによる表示 | 通常の描画を隠している物体を、本来のマテリアルで見せる |

それぞれ「表示範囲」を選べます。

- **接触部分表示**：波が届いた表面だけを表示する。
- **全体表示**：物体のどこかに波が届けば、その `EchoTarget` が持つ Renderer 全体を表示する。

「接触終了後も表示を残す」で残存秒数を設定できます。接触部分表示の残存は、物体のローカル座標の 3D テクスチャに接触時刻を記録するので、物体やカメラが動いても記録がずれません。

### 遮断

- 専用タグのない物体（`EchoTarget` がない、またはタグ未設定）は波を遮断します。
- 専用タグのある物体は、アセットの「エコーロケーションを遮断する」に従います。表示をすべてオフにして、遮断専用のタグにすることもできます。
- 遮断の判定は「エコーが発生した位置」から行います（カメラの位置ではありません）。Controller の「影になる部分を強調しない」がオンのときに有効です。
- 各表示の「壁越しに表示する」は、カメラとの間の壁を無視して描く設定です。発生位置から遮断された波を貫通させる設定ではありません。

## 透明・照射中・実体化

専用タグで「通常の描画を隠す」をオンにすると、その物体は透明な状態から始まり、エコーを当て続けると実体化します。

```
透明 ──接触──▶ 照射中 ──照射時間が必要秒数に達する──▶ 実体化
 ▲               │                                        │
 └──接触が途切れる─┘（途切れたときの扱いは設定で選ぶ）           │
 ▲                                                        │
 └────────── 一定時間で透明に戻る設定のとき ────────────────┘
```

| 状態 | 見え方 |
|---|---|
| 透明（`Transparent`） | 通常の描画は隠れている。照射中の表示も出ない（残存表示は出る） |
| 照射中（`Irradiated`） | エコーが当たっている。「照射中の表示」①②③で描く |
| 実体化（`Materialized`） | 透明化が解除され、通常の描画で見える。「実体化しているときの表示」①②で強調する（③は描かない） |

- **照射が途切れたとき**：「0 に戻す」「保持する」「徐々に減らす」から選ぶ。
- **実体化した後**：「ずっと実体化」か「一定時間で透明に戻る」（最後に当たってから指定秒数）。
- **シームレスな移行**：照射中の表示①②③ごとに「実体化へシームレスに移行する」を選べる。照射時間の進み具合に合わせて、色・幅・不透明度を実体化したときの見た目へ近づける。実体化したときにその表示がオフなら、同じ色のまま消えていく。
- **当たり判定**：「透明な間は当たり判定を無効にする」をオンにすると、実体化するまで自身と子の Collider を無効にする（子の `EchoTarget` が持つものは除く）。再生中だけ切り替え、元から無効だった Collider は有効にしない。
- 「通常の描画を隠す」がオフの専用タグは、最初から実体化として扱う。

## 判定のしくみと遅れ

- 接触は GPU で判定し、結果を非同期で読み戻します。そのため、表示や `IsRevealed`・`IsInContact`・実体化の状態は、画面より 1〜3 フレーム遅れて変わります。
- Collider や Mesh の Read/Write 設定は不要です。
- 全体表示の接触判定は、物体全体を 3 方向から描いて調べます。細い物体や大きな物体で取りこぼす場合は、専用タグの「全体接触判定の解像度」を上げてください。
- 通常の描画を隠すときは、Renderer のマテリアル参照を一時的に専用の透明マテリアルへ差し替えます。元のマテリアルのアセット自体は変更しません。Controller の無効化、タグの変更、実体化などで元の参照に戻します。

## 対応範囲と制限

- 対応：MeshRenderer、SkinnedMeshRenderer、複数サブメッシュ、LODGroup、URP の Forward／ForwardOnly／Unlit パス。
- 非対応（専用の拡張が必要）：Terrain、Sprite、VFX、別の描画パイプライン。
- アルファで切り抜いた模様や独自シェーダーの頂点変形は、輪郭・接触判定に反映されません。
- SkinnedMeshRenderer を画面外でも更新する場合は、`Update When Offscreen` と bounds を確認してください。
- 標準の構成は、プレイヤー 1 人・Base Camera 1 つです。
- 通常の描画を隠すマテリアルスロットは、同時に 5000 までです。
- 接触部分の残存は、残存を使う物体だけに 3D の記録領域を確保します。1 物体あたり、残存精度 32 で約 128KiB、64 で約 1MiB、128 で約 8MiB です。シェーダーモデル 5.0 が必要です。
- 全体表示や残存は追加の GPU 処理を使います。対象が多い場合は、専用タグの解像度や Controller の対象レイヤーで絞ってください。

## 旧方式の互換コンポーネント

次のコンポーネントは、古いシーンが Missing Script にならないように残しているものです。新しく付ける必要はなく、Add Component の一覧にも出ません。

| コンポーネント | 現在の扱い |
|---|---|
| `EchoTag` | `EchoTarget` の専用タグが未設定の間だけ、その指定を使う |
| `EchoRangeDisplay` | 再生中だけ、値を Controller の範囲表示へ引き継ぐ |
| `EchoRevealWorld`／`EchoRevealState`／`EchoRevealCollider` | 互換用。部分的な当たり判定などの旧機能は動作しない |
| `EchoOccluder` | 判定には使わない |

古いシーンは **Tools → エコーロケーション → 既存シーンの移行** で新しい構成へ移せます（[02_導入手順.md](02_導入手順.md#既存シーンの移行)）。
