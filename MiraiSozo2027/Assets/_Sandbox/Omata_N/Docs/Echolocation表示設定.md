# エコーロケーションの表示設定

`EchoController` のインスペクター → **対象と表示 → タグと表示設定** で設定します。
既存のタグ行は従来どおり「表面を色で塗る」だけが有効です。新機能は必要なタグの行で有効にしてください。
同じタグを複数行に分けず、1行の中で各表示を併用します。タグが重複した場合は上の有効行が優先されます。

## 輪郭だけを表示

1. 対象のタグを選択します。
2. **表面を色で塗る**をOFF、**全体の輪郭を表示**をONにします。
3. **輪郭の色 / 不透明度**、**輪郭幅（px）**、**接触後の輪郭残存（秒）**を調整します。

物体のどこかに波が届くと、画面に映る物体全体のシルエットの内側に輪郭を描きます。波との境界や三角形の線は描きません。
元のマテリアルが通常表示されている物体は、その見た目の上に輪郭を重ねます。

## 普段は透明にし、エコーで元の見た目を表示

1. Rendererには、本来表示したいマテリアルを設定します。RendererとGameObjectは有効のままにします。
2. タグ行の**元のマテリアルを表示**と**通常時は非表示にする**をONにします。
3. **接触後の表示残存（秒）**に `n` を設定します。`0` は接触中のみです。
4. **元の見た目の不透明度**で、表示時の濃さを調整します。

接触中は表示し続け、最後の接触から `n` 秒後に非表示になります。再接触すると期限を延長します。
スキャンをOFFにした場合も残存時間は有効です。時間はControllerの「ゲーム時間 / 実時間」に従います。
「表面を色で塗る」「全体の輪郭を表示」もONにすると、元の見た目と同時に表示できます。
**通常時は非表示にする**をOFFにすると元の見た目は常時表示され、元マテリアルの残存時間・不透明度は適用されません。

透明化のために元マテリアルのアルファを0にする必要はありません。元から透明なマテリアルは、その透明度も含めて元の見た目を再現します。
通常描画を隠す間だけRendererのマテリアル参照を専用の非表示用マテリアルに差し替え、元マテリアルのアセット自体は変更しません。
Controllerの無効化、タグ変更、設定解除時には元の参照を復元します。実行中に元のマテリアルを取得するコードでは `EchoTargetRegistry.GetOriginalMaterials(renderer)` を使用できます。

## 複数の子Rendererをまとめる

親に `EchoTarget` を付け、親に対象タグを設定してください。子のどれかに波が触れると、その `EchoTarget` が所有するRenderer全体を表示します。
子にも別の `EchoTarget` がある場合、その子は別の物体です。`EchoTarget` がない場合はRenderer単位です。

## 機能ごとの壁越し表示

タグ行で各機能をONにすると、**塗りの壁越し表示**・**輪郭の壁越し表示**・**元マテリアルの壁越し表示**をそれぞれ選択できます。

- **共通設定に従う**：Controllerの「共通の壁越し表示」を使用します。既存データの初期値です。
- **壁越しに表示する**：カメラとの間に壁があっても表示します。
- **壁で隠す**：カメラの深度情報に従って壁の裏を隠します。

例えば塗り・輪郭を「壁越しに表示する」、元マテリアルを「壁で隠す」にすると、壁の裏は強調表示だけが見えます。実行中の変更も反映されます。
これは表示の設定です。波自体の到達判定には引き続き「エコー地点からの遮蔽」が適用されます。深度を書き込まない透明マテリアルは、表示を遮る壁として扱われません。

## 調整と対応範囲

- 「エコー地点からの遮蔽」は各機能で共有します。遮蔽物で波が届かない場合、新しい接触として扱いません。残存表示は設定した時間だけ続きます。
- 接触は画面外も含め、物体全体を3方向からGPUで描いて判定します。ColliderやメッシュのRead/Write設定は不要です。
- **接触判定の解像度**は64〜1024（2の累乗）です。大きな物体の細い部分や小さな接触を拾いにくい場合は上げてください。標準は256です。
- MeshRenderer / SkinnedMeshRenderer、URPのForward / ForwardOnly / Unlitパスに対応します。スキンの画面外更新には `Update When Offscreen` と適切なboundsを設定してください。
- 輪郭はメッシュのシルエットです。アルファで切り抜いた模様・独自シェーダーの頂点変形は輪郭・接触判定には反映しません。
- 元マテリアル表示は専用の追加描画です。通常時非表示の物体はシーンの通常深度や影を生成しません。屈折など特殊な描画パスのみを使う独自シェーダーは個別対応が必要です。
- 全体表示は追加のGPU処理を使用します。多数の対象ではタグ・対象レイヤー・解像度を絞ってください。

検証用テストは `EchoRenderingTests` と `EchoTagResolverTests` にあります。

## チーム操作

操作は共有の `PlayerController` と `InputSystem_Actions.inputactions` に統一しています。試作用入力・移動・操作案内・旧プレイヤーPrefab・入力を停止する常駐連携処理は撤去しました。エコーは `Player/EchoScan` から `EchoController.ToggleScan()` を呼びます。チーム入力の初期化には `GameManager` が必要です。

`Scene_EchoDemo` は `_Project/Scenes/TestScene` の `Test_Player`・`Main Camera`・`GameManager`（GameSettings付き）・`Canvas`・`EventSystem` を使用します。共有Prefabへの参照を維持し、エコーのタグ別表示・遮蔽・残存時間・範囲表示・FPS上限はシーンのOverrideとして保持しています。

調整先はシーン内 `Test_Player` の `EchoController` です。個人の調整は共有PrefabにApplyせず、シーンのOverrideとして保存してください。Wで移動、EでエコーON/OFF、Escでポーズ／復帰します。

旧デモ生成メニューは撤去しました。「移植先の初期設定」「Renderer Featureを設定」は描画設定用として残しています。
