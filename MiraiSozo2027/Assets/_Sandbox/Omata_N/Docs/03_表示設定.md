# エコーロケーション 表示設定

Inspector に出る設定項目の一覧です。（　）内は初期値です。仕組みは [01_全体仕様.md](01_全体仕様.md) を参照してください。

## EchoController

プレイヤーに付けるコンポーネントです。

### 基本

| 項目 | 内容 |
|---|---|
| スキャン中心 | エコーの中心にする Transform。未設定なら Controller 自身 |
| 正面の基準 | 正面の向きにする Transform。未設定ならスキャン中心の forward |
| 描画カメラ | 強調表示を描く Base Camera |
| 最大半径（m） | 波が届く最大の距離（10）。Transform の Scale には影響されない |
| 全開き角（度） | 正面を中心とした角度（360）。片側はこの半分。360 で全方向 |
| 伝播時間（秒） | 半径 0 から最大半径まで広がる秒数（1）。0 なら即時 |
| スキャン方式 | ライト方式／断続方式／単発方式（ライト方式） |

### スキャン範囲の表示

スキャン方式のすぐ下にあります。スキャン範囲そのもの（検出範囲）は変えず、見た目だけを設定します。

| 項目 | 内容 |
|---|---|
| スキャン範囲を表示 | 範囲表示全体のオン／オフ。新しく追加した Controller ではオン、既存シーンではオフで読み込む |
| 床・壁に範囲を表示 | 見えている床や壁の、範囲内の部分を薄く色付けする（オン） |
| 空間の境界線を表示 | 範囲の形（球の扇形）の経線・緯線を描く（オン） |
| 範囲内の色 | 範囲内の表面の色。A は不透明度 |
| 拡張波の色 | 外側へ進む波の色 |
| 消去波の色 | OFF で手前から消える波の色 |
| 境界線の色 | 空間の境界線の色 |
| 波の帯幅（m） | 波の帯の幅（0.3）。単発方式では当たり判定の帯の幅にもなる |

### 方式ごとの設定

選んだスキャン方式の設定だけが表示されます。

**ライト方式**

| 項目 | 内容 |
|---|---|
| 拡張波を繰り返す間隔（秒） | 広がりきった後、この間隔ごとに中心から拡張波を表示する（0 = 出さない）。見た目だけで、検出範囲は変わらない。伝播時間 0 では表示されない |
| 持続可能な時間を設定する | オンで時間制限を付ける（オフ = 時間制限なし） |
| 　持続可能な時間（秒） | ON のまま照らし続けられる秒数（10、最小 0.1） |
| 　使い切ったとき | 自動でOFFになる／最小の範囲で照らし続ける（自動でOFFになる） |
| 　回復のしかた | OFFの間に回復する／OFFにすると満タンに戻る／回復しない（OFFの間に回復する） |
| 　回復する速さ（秒/秒） | OFF の 1 秒あたりに回復する秒数（1）。「OFFの間に回復する」のときだけ表示 |
| 　残り時間に応じて最大半径を狭める | オンにすると、残り時間に合わせて最大半径から下の値へ狭める |
| 　　0になった時の最小の距離（m） | 残り時間 0 のときの半径（2）。最大半径より大きい値は最大半径に合わせる |
| 　残り時間に応じて全開き角を狭める | オンにすると、残り時間に合わせて全開き角から下の値へ狭める |
| 　　0になった時の最小の角度（度） | 残り時間 0 のときの全開き角（30）。全開き角より大きい値は全開き角に合わせる |

「回復しない」を選んだ場合は、スクリプトから `RecoverLightSustain` / `RefillLightSustain` を呼んで回復させます（[04_スクリプトからの使い方.md](04_スクリプトからの使い方.md)）。

**断続方式**

| 項目 | 内容 |
|---|---|
| 再展開間隔 n（秒） | 波を出し直す間隔（2、最小 0.05）。同時に 64 波を超える設定では自動で間隔を広げる |
| 展開後の残存時間 m（秒） | 最大半径まで広がってから残る時間（3）。各波は「伝播時間 + m 秒」で消える |

**単発方式**

| 項目 | 内容 |
|---|---|
| 連続で打てる回数（ストック） | ストックの最大数（1、1〜64）。この数まで連続で打てる |
| ストック1回復までの時間（秒） | ストックが 1 回復するまでの秒数（2）。0 なら打った直後に回復 |

- ストックが 0 の間の ON 操作は無視されます。最大数を変えると満タンから始まります。
- 当たり判定は先端から「波の帯幅」までの帯の中だけです。伝播時間 0 では波が一瞬で通り過ぎるため、何にも当たりません。

### 共通の動作

| 項目 | 内容 |
|---|---|
| 停止時の消し方 | 即時／手前から順番（即時） |
| 時間の基準 | ゲーム時間（ポーズ中は止まる）／実時間（ポーズ中も進む）（ゲーム時間） |
| 開始時に有効 | 有効になったときにエコーを開始する（オフ） |

### エコー地点からの遮蔽

| 項目 | 内容 |
|---|---|
| 影になる部分を強調しない | エコーの発生位置から見て、遮断する物体の裏にある部分を強調しない（オン） |
| 影の解像度（1方向） | 影の細かさ（512、128〜1024）。上げると境界がきれいになるが、GPU 負荷とメモリが増える |
| 表面の誤判定を防ぐ距離（m） | （0.03、0.001〜0.2）。小さすぎると表面に影の模様が出やすく、大きすぎると薄い壁を通り抜けて見える |

遮断するかどうかは物体の専用タグで決まります（タグなしの物体は遮断します）。除外するルートの配下は影を作りません。動く壁も毎フレーム反映します。

### 対象と表示

| 項目 | 内容 |
|---|---|
| 対象レイヤー | 対象にするレイヤー（すべて）。`EchoTarget` を付けた GameObject のレイヤーで判定する |
| 除外するルート | この階層の配下を強調表示・遮断の対象から外す。プレイヤー自身を指定する |
| 対象を自動収集 | 起動時・シーン追加時に Renderer を集める（オン）。オフにすると `EchoTarget` の付いた物体だけを集める |

表示と遮断の設定は、Controller ではなく専用タグのアセットで編集します。

### その他

| 項目 | 内容 |
|---|---|
| 範囲をシーン画面に表示 | Scene ビューにギズモを表示する（オン）。水色は設定上の最大の範囲、緑は実行中の今の範囲、赤は消去中の範囲 |
| 状態変更時の通知 | 状態（非表示・展開中・表示中・消去中）が変わったときに呼ぶ UnityEvent。旧状態・新状態の順に渡す |
| セットアップを検証（ボタン） | 描画カメラ・描画機能・URP・非対応 Renderer などを確認し、Console に出す |
| 動作確認 | 状態・半径・登録数などの表示と、開始／停止／切り替え／対象を再収集のボタン。ライト方式の残り時間、単発方式のストックもここに出る |

## 専用タグ

**Create → エコーロケーション → 専用タグ** で作るアセット（`EchoTagDefinition`）です。同じアセットを使う物体は、すべて同じ設定になります。

### 基本

| 項目 | 内容 |
|---|---|
| 表示名・説明 | メモ用。表示名が空ならアセット名を使う |
| エコーロケーションを遮断する | この物体が波を止めるか（オン） |
| 全体接触判定の解像度 | 全体表示の接触判定の細かさ（256、64〜1024 の 2 の累乗）。大きい物体や細い物体で取りこぼすときに上げる。上げると GPU 負荷が増える |
| 接触部分の残存精度 | 接触部分の残存を記録する細かさ（32、16〜128 の 2 の累乗）。上げると境界が細かくなり、記録メモリが増える（32 で約 128KiB、64 で約 1MiB、128 で約 8MiB／物体）。接触部分の残存を使う物体だけに確保する |

### 通常の描画を隠す

オンにすると、物体は透明な状態から始まり、エコーを当て続けると実体化します。オンのときだけ、下の「実体化の条件」と「照射中の表示」が表示されます。

**実体化の条件**

| 項目 | 内容 |
|---|---|
| 実体化までの照射時間（秒） | この秒数エコーを当て続けると実体化する（1）。0 なら当たった瞬間に実体化 |
| 照射が途切れたとき | 0に戻す／保持する／徐々に減らす（0に戻す） |
| 　減る速さ（秒/秒） | 当てていない 1 秒あたりに減らす照射時間（1）。「徐々に減らす」のときだけ表示 |
| 実体化した後 | ずっと実体化／一定時間で透明に戻る（ずっと実体化） |
| 　透明に戻るまでの時間（秒） | 最後にエコーが当たってからこの秒数で透明に戻る（5）。「一定時間で透明に戻る」のときだけ表示 |
| 透明な間は当たり判定を無効にする | 実体化するまで、自身と子の Collider を無効にする（オフ）。子の `EchoTarget` が持つ Collider は対象外 |

**照射中の表示**

透明な間、エコーが当たっている部分の表示です。下の「表示 ①②③ の共通項目」に加えて、次があります。

| 項目 | 内容 |
|---|---|
| 実体化へシームレスに移行する | 照射時間の進み具合に合わせて、実体化しているときの同じ番号の表示へ色・幅・不透明度を近づける。③は不透明度を 1（通常の描画）へ近づける。実体化しているときの表示がオフなら、同じ色のまま消えていく |
| 実体化しているときの①／②／③をコピー | その番号の表示だけを、実体化しているときの設定からコピーする。「実体化へシームレスに移行する」のチェックは変えない |
| 実体化しているときの表示をコピー | ①②③をまとめてコピーする |

コピーは Undo でき、複数のタグを選んでいるときは全部に反映されます。

### 実体化しているときの表示

実体化しているとき（通常の描画を隠さないタグでは常に）、エコーが当たっている部分の表示です。実体化中は通常の描画で見えているため、③は表示されません。

### 表示 ①②③ の共通項目

①塗りつぶし・②アウトライン・③元のマテリアルの枠それぞれに、次の項目があります。

| 項目 | 内容 |
|---|---|
| 表示する | この表示のオン／オフ |
| 壁越しに表示する | カメラとの間に壁があっても表示する。発生位置からの遮断は無視しない |
| 表示範囲 | 接触部分表示（届いた表面だけ）／全体表示（どこかに届けば物体全体） |
| 接触終了後も表示を残す | オンにすると、接触が終わった後も残す |
| 　残存時間（秒） | 残す秒数。接触部分表示は各表面が最後に当たってから、全体表示は物体のどこかに最後に当たってから数える |

表示ごとの見た目の項目です。

| 表示 | 項目 | 内容 |
|---|---|---|
| ① 塗りつぶし | 強調色 / 不透明度 | 塗る色。A が不透明度 |
| ② アウトライン | 輪郭の色 / 不透明度 | 輪郭線の色 |
| ② アウトライン | 輪郭の幅（ピクセル） | 画面上の輪郭の太さ（3、1〜16）。シルエットの内側に描く |
| ③ 元のマテリアル | 表示の不透明度 | 元のマテリアルで見せるときの濃さ |

## EchoTarget

エコーで表示したい物体のルートに付けます（Add Component → Echo → Echo Target）。

| 項目 | 内容 |
|---|---|
| 専用タグ | 表示と遮断の設定を持つアセット。未設定なら表示せず、遮断する物体として扱う |
| Rendererを手動指定 | オンにすると、「対象Renderer」に指定した Renderer だけを集める（オフ = 自身と子の Renderer をすべて集める） |
| 対象Renderer | 自身または子の Renderer。重複や、子の `EchoTarget` が持つものは指定できない |
| 子Rendererの登録を更新（ボタン） | 子の構成を変えた後に押す |

- 子のどれかに波が届くと、その `EchoTarget` が持つ Renderer 全体を 1 つの物体として扱います（全体表示・実体化など）。
- 子にも別の `EchoTarget` がある場合、その子は別の物体として扱います。

再生中は **実行中の状態** に、透明・照射中・実体化の状態、実体化までの進み具合、照射時間が表示されます。「実体化させる」「透明に戻す」ボタンで状態を切り替えて確認できます。

## EchoStockDisplay

単発方式のストック数を画面の隅に表示する UI です。表示用の Canvas はこのコンポーネントが自分で作ります。Inspector の項目名は英語のままです。

| 項目 | 内容 |
|---|---|
| Controller | 表示する Controller。未設定ならシーン内から探す |
| Corner / Margin | 表示する画面の隅（右下）と、端からの距離（32, 32 ピクセル） |
| Format | `{0}` が今のストック、`{1}` が最大数（`ECHO {0} / {1}`） |
| Font Size / Text Color / Empty Color | 文字の大きさ（36）、通常の色、ストック 0 のときの色 |
| Is Recharge Bar Visible / Bar Color / Bar Background Color | 次の回復までのゲージを表示するか（オン）と、その色・背景色 |
| Is Hidden Outside Once Mode | スキャン方式が単発方式以外のときは表示しない（オン） |
| Font | TextMeshPro のフォント。標準フォントは英数字だけなので、日本語を出すときは日本語対応フォントを指定する |

## EchoFrameRateLimiter

| 項目 | 内容 |
|---|---|
| FPS上限を有効にする | オフで PC 版の FPS 上限を解除する（オン）。コンポーネント自体を無効にすると、適用前の設定に戻す |
| 上限FPS | 上限の値（60）。再生中の変更も反映する |
