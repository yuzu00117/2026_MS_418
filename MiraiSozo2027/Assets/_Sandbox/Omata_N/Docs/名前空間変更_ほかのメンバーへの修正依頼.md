# エコーロケーションの名前空間変更に伴う修正のお願い

コーディング規約「1.5 名前空間」（`Aura.<機能名>` にする）に合わせて、エコーロケーションの名前空間を変更しました。

| 変更前 | 変更後 |
|---|---|
| `Echo.Echolocation` | `Aura.Echolocation` |
| `Echo.Echolocation.Editor` | `Aura.Echolocation.Editor` |

エコーロケーションを使っているスクリプトのうち、Omata_N の外にあるのは次の 2 ファイルです。`using Echo.Echolocation;` のままだとコンパイルエラーになるため、それぞれ修正をお願いします。

- 修正するのは `using` の 1 行だけです。クラス名・メソッド名・Inspector の設定は変わりません。
- asmdef の名前（`Echo.Runtime` など）は変えていないので、asmdef の参照はそのままで動きます。
- シーンや Prefab に付けたコンポーネントの参照も外れません。

---

## 1. `EchoWaveRevealSource.cs`（修正済み）

> 担当者の許可を得て、名前空間変更の PR で修正しました。作業は不要です。

**場所**：`Assets/_Project/Scripts/Wave/Echo/EchoWaveRevealSource.cs`（3 行目）

```csharp
// 変更前
using Echo.Echolocation;

// 変更後
using Aura.Echolocation;
```

- このファイルの名前空間は `Aura.Wave.Echo` のままで問題ありません。
- 同じフォルダの `Aura.Wave.Echo.asmdef` は、参照先が `Echo.Runtime`（asmdef の名前）なので変更不要です。
