## 命名と公開方法

- privateフィールドを `_camelCase` に統一。
- boolフィールド・プロパティ・引数・ローカル変数に `is`／`has`／`can` の接頭辞を付けた。
- 定数はPascalCase、コレクションは複数形に整理。
- Inspector用のpublicフィールドを `[SerializeField] private` と公開プロパティに分離。
- Inspectorに保存しない描画データ等も、publicフィールドからプロパティへ整理。
- 列挙型・ネストしていたデータ型を含め、C#を1ファイル1型・ファイル名と型名が同一になるよう分離（68ファイル）。
- `ForCamera` → `GetForCamera`、`Distance` → `GetDistance` など、役割が分かるメソッド名へ変更。

API名を変えた箇所はプロジェクト内の呼び出しも更新した。例：`Settings.Shadow.Enabled` → `Settings.Shadow.IsEnabled`、`RequestedOn` → `IsScanRequested`、`LimitEnabled` → `IsLimitEnabled`。外部プロジェクトへコピー済みの呼び出し元がある場合は同様に更新する。詳細な対応表はワークスペースの `Artifacts/CodingRules/renames.txt` と `collection-renames.txt` に保存した。
