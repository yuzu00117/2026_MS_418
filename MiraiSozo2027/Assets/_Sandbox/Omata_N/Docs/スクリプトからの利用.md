# スクリプトからエコーロケーションの状態を使う

ゲームロジックから「エコーを使っているか」「この物体は今エコーで表示されているか」を知るためのAPIです。名前空間は `Echo.Echolocation` です。

## 1. Controller：エコーを使用中か

`EchoController`（プレイヤー側）で取得します。

| API | 種類 | 内容 |
|---|---|---|
| `IsEchoInUse` | `bool` | エコーを使用中か。ON中（ソナーの波と波の間も含む）と、OFF後に波が消えきるまでが `true`。「一回だけ」では波の帯が最大半径を抜けきるまで |
| `UsageChanged` | `event Action<bool>` | `IsEchoInUse` が変わった時に新しい値を通知 |
| `IsScanRequested` | `bool` | ON/OFFの操作状態だけ。OFFにした瞬間に `false`（消去中の波は含まない） |
| `OnceStock` | `int` | 「一回だけ」で今打てる回数 |
| `OnceRechargeProgress` | `float` | 次のストックが回復するまでの進み具合（0～1、満タンなら1）。回復ゲージの表示に使う |
| `OnceStockChanged` | `event Action<int>` | ストック数が変わった時に新しい値を通知 |
| `CurrentState` / `StateChanged` | `EchoState` / `event Action<EchoState, EchoState>` | 非表示・展開中・表示中・消去中の詳細な状態 |

```csharp
using Echo.Echolocation;
using UnityEngine;

public sealed class EchoBatteryDrain : MonoBehaviour
{
    [SerializeField] private EchoController _echo;
    [SerializeField] private float _drainPerSecond = 5f;
    private float _battery = 100f;

    private void OnEnable() => _echo.UsageChanged += HandleUsageChanged;
    private void OnDisable() => _echo.UsageChanged -= HandleUsageChanged;

    private void Update()
    {
        // 使用中だけ毎フレーム減らす。
        if (_echo.IsEchoInUse)
            _battery -= _drainPerSecond * Time.deltaTime;
    }

    private void HandleUsageChanged(bool isInUse)
    {
        // 開始・終了の瞬間だけ処理したい場合はイベントを使う。
        Debug.Log(isInUse ? "エコー開始" : "エコー終了");
    }
}
```

## 2. EchoTarget：表示されているか

`EchoTarget`（物体側）で取得します。

| API | 種類 | 内容 |
|---|---|---|
| `IsRevealed` | `bool` | 塗りつぶし・輪郭・元マテリアルのどれかを表示中か。接触後の残存表示中も含む |
| `RevealChanged` | `event Action<EchoTarget, bool>` | `IsRevealed` が変わった時に、対象と新しい値を通知 |
| `IsInContact` | `bool` | 波が今この物体に届いているか（残存表示は含まない） |
| `LastContactTime` | `float` | 最後に波が届いた時刻。Controllerの「時間の基準」（ゲーム時間／実時間）に合わせた値。未接触は負の無限大 |

```csharp
using Echo.Echolocation;
using UnityEngine;

[RequireComponent(typeof(EchoTarget))]
public sealed class EnemyRevealReaction : MonoBehaviour
{
    private EchoTarget _target;

    private void Awake() => _target = GetComponent<EchoTarget>();
    private void OnEnable() => _target.RevealChanged += HandleRevealChanged;
    private void OnDisable() => _target.RevealChanged -= HandleRevealChanged;

    private void HandleRevealChanged(EchoTarget target, bool isRevealed)
    {
        // 見つかった瞬間・見えなくなった瞬間の処理。
        if (isRevealed) Debug.Log($"{target.name} がエコーで見つかった");
        else Debug.Log($"{target.name} が見えなくなった");
    }
}
```

毎フレーム判定する場合は `if (_target.IsRevealed) { ... }` のように参照します。

## 注意点

- **判定はGPUの描画結果と同じ**：エコー地点から壁で遮られて表示されていない物体は `false` になります。
- **1～3フレーム遅れる**：結果はGPUから非同期で読み戻すため、画面の表示より少し遅れて変わります。毎フレームの厳密な同期が必要な処理には向きません。
- **最初に参照した時点から追跡を始める**：読み戻しの負荷を必要な物体だけに掛けるため、`IsRevealed`・`IsInContact`・`LastContactTime` を初めて読んだ時、または `RevealChanged` を購読した時から判定を始めます。最初の数フレームは `false` です。開始直後から必要な場合は `Start` などで一度参照しておいてください。
- **表示設定がない物体は常に `false`**：専用タグが未設定、またはタグで4つの表示がすべてOFFの物体は表示されないため `false` です。
- **描画カメラが映している間だけ更新**：判定はControllerの描画カメラの描画処理の中で行います。カメラが無効の間やControllerが無効の間は `false` になります。画面外にある物体の判定は、カメラが有効なら行います。
- **イベントの解除**：`OnDisable` などで必ず `-=` で解除してください。
