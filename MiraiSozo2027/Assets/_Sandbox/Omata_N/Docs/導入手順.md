# エコーロケーションの使い方

## チームのシーンで使う

`Scenes/Scene_EchoDemo.unity` を開いて再生します。`_Project` のチームプレイヤー・カメラ・GameManager・ポーズUIを使用します。Wで移動、EでエコーのON/OFF、Escでポーズ／復帰します。キー割り当ては共有の `InputSystem_Actions.inputactions` で管理します。

別のシーンへ導入するときはチームの `Test_Player` と必要なカメラ・GameManagerを配置し、`EchoController` の描画カメラ、スキャン中心、正面の基準、除外ルートを確認してください。シーン内の設定変更はPrefabのOverrideとして保存します。

描画Featureが未登録の場合は **Tools → エコーロケーション → Renderer Featureを設定** を実行します。「移植先の初期設定」は描画FeatureとEchoEnemy／EchoItem／EchoStructureタグを登録します。これらは共有の描画アセットやタグ設定を変更するため、チームの導入手順に従って使用してください。旧試作用プレイヤーとその生成メニューは撤去済みです。

## 表示と動作の調整

Hierarchyの `Test_Player` を選びます。

- **Echo Controller**：スキャン半径・角度・波の間隔・残存時間・タグ別の塗り／輪郭／元マテリアル表示を設定します。詳細は [表示設定](../Echolocation表示設定.md) を参照してください。
- **Echo Range Display**：範囲の表面表示と境界線、色、波の帯幅を設定します。無効化すると範囲表示だけを消せます。
- **Echo Frame Rate Limiter**：上限FPSを変更します。無効化すると、このコンポーネントによるFPS制限を解除します。

スキャン中心はプレイヤー側に置き、三人称カメラの後退位置を中心にしないでください。移動・カメラ・ポーズはチーム側のコンポーネントで管理します。

## 動的生成と外部スクリプト

動的に生成するPrefabには `EchoTarget` を付けてください。自動収集だけを使う場合は生成後に `EchoController.RefreshTargets()` を呼びます。子RendererやLOD構造を変更した場合は `EchoTarget.RefreshRenderers()` で再収集してください。

入力側から利用するAPIは `SetScanEnabled(bool)` と `ToggleScan()` です。同じ操作から複数回呼び出さないようにしてください。

## 対応範囲

MeshRenderer／SkinnedMeshRenderer、複数サブメッシュに対応します。Terrain・Sprite・VFXや別の描画パイプラインには専用の拡張が必要です。透明テクスチャの切り抜きや独自の頂点変形は各強調表示で完全には再現しません。

標準構成は単一プレイヤー・1つのBase Cameraです。Gameの強調表示は指定したCameraに描画します。

## エコー地点から見て影になる部分を隠す

Player → Echo Controller → **エコー地点からの遮蔽** を開きます。「影になる部分を強調しない」をONにすると、各エコー地点から壁などの裏にある部分が強調されなくなります。カメラの位置ではなく、エコーが発生した位置から判定します。元の球・扇形、進行速度、n秒ごとの再展開、m秒の残存、OFF消去はそのままです。

**「タグと遮断設定」** に行を追加し、タグと以下のどちらかを選びます。

- **遮断する**：その面の後ろを影にする。壁・地面向け。
- **遮断しない（透過）**：距離を減らさず通す。その先の別の壁では止まる。

デモではEchoStructureを遮断、EchoEnemy／EchoItemを透過に設定しました。未登録タグは「未登録タグは遮断する」で決めます。タグはRendererが付いているGameObjectのものを使います。色のタグ一覧とは別設定です。

同じ物体の一部分だけが影になった場合も、その部分だけを隠します。遮断面そのものは強調できます。プレイヤーの除外ルート配下は影を作りません。壁が動いた場合は毎フレーム影を更新します。古いソナー波は発生位置を保ち、それぞれの位置から影を計算します。

「壁越し表示 → 表示する」はカメラからの壁越し表示です。エコー地点からの影まで無視する設定ではありません。強調対象同士を重ねて両方見せたい場合は、手前側のタグを「遮断しない」にしてください。

「影の解像度」は標準512。境界が粗い場合は1024へ上げられますが、GPU負荷とメモリ使用量が増えます。「表面の誤判定を防ぐ距離」は標準0.03m。小さすぎると表面に影の模様が出やすく、大きすぎると薄い壁を通り抜けて見えます。

MeshRenderer／SkinnedMeshRendererに対応し、ColliderやRead/Write Enabledは不要です。透明マテリアルの穴・独自頂点シェーダー変形・Terrainは対応外です。骨アニメーションを画面外でも更新する場合はUpdate When Offscreenとboundsを確認してください。LightやCameraをHierarchyに追加する必要はありません。

旧反射・残距離配分・波面メッシュの設定は撤去しました。以前のコードはプロジェクト外の `Artifacts/Retired-reflection`、変更前のファイルは `Artifacts/Before-source-shadow-update` に保存しています。Unityでシーンを開いたままの場合は再生を止め、コンパイル後に設定を確認してください。
